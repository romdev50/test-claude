## Repas de la semaine (`repas/`)

Application web installable (PWA), utilisable sur smartphone, pour :

- **Planifier** les repas de la semaine, en choisissant les jours et les repas à prévoir (midi et/ou soir), avec le nombre de personnes par repas.
- **Gérer ses recettes** : ingrédients (quantité, unité, rayon) et étapes de préparation. 41 recettes sont fournies pour démarrer (végétariennes, poisson, rapides, mijotées…), avec un filtre par étiquette.
- **Préparer les courses** en deux étapes :
  1. *J'ai déjà ?* : pour chaque ingrédient (quantités additionnées et ajustées au nombre de personnes), indiquer « J'ai » ou « Acheter ».
  2. *Ma liste* : seuls les produits « à acheter », classés par rayon, avec un bouton 🔍 qui ouvre la recherche du produit sur le drive choisi, une case à cocher pour suivre le panier, et des boutons copier / partager.
- **Choisir son drive** : E.Leclerc, Carrefour, Auchan, Intermarché, Courses U, Monoprix, Chronodrive, ou une adresse personnalisée.
- Garder une liste d'ingrédients **toujours au placard** (sel, poivre…).
- **Exporter / importer** ses données.

Les données sont enregistrées dans le navigateur de l'appareil (aucun compte requis).
Pour l'installer sur un téléphone : ouvrir la page puis « Ajouter à l'écran d'accueil ».
